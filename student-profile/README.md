# Student Profile — React + Vite

A simple React application demonstrating functional components and props.

## How to run

1. Unzip the project.
2. Open a terminal inside the `student-profile` folder.
3. Install dependencies:
   ```
   npm install
   ```
4. Start the development server:
   ```
   npm run dev
   ```
5. Open the URL shown in the terminal (usually `http://localhost:5173`).

## Project structure
```
student-profile/
├── src/
│   ├── App.jsx        # Renders two Student components with different props
│   ├── Student.jsx    # Functional component that receives and displays props
│   ├── main.jsx        # App entry point
│   └── style.css       # Basic styling
├── index.html
├── package.json
└── vite.config.js
```
